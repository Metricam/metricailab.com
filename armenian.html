Armenian LLM

A large language model trained from scratch with an Armenian-efficient tokenizer. Existing models waste tokens on Armenian script — we're fixing that with our own data pipeline.

Published · EACL 2026 · LoResLM Workshop

Adapting Text Embeddings to Low-Resource Languages with Noisy Translations

The methodology behind ATE: state-of-the-art embedding quality in a low-resource language using only 10k noisy translations. Applied to Armenian; validated on Georgian and Uzbek — it generalizes to any underrepresented language.
